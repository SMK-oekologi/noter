# Værtsplanter og ikke-værter

| Afhængighed          | Afgrøder                                                                            |
| -------------------- | ----------------------------------------------------------------------------------- |
| Meget afhængige      | løg, porre, hvidløg (få rodhår), majs, bønner, ærter, tomat, squash, agurk, gulerod |
| Middel               | kartoffel, salat, selleri                                                           |
| **Ingen mykorrhiza** | kålfamilien (kål, radise, rucola, sennep, olieræddike), spinat, rødbede, mangold    |

## Konsekvenser
- Efter kål eller spinat er der færre svampe i jorden. Sæt derfor ikke porrer, løg eller majs lige efter. Se [[Minimum-sædskifte]].
- Brug ikke sennep og olieræddike som [[Efterafgrøder]].
- [[Hvidkløver]] som bunddække i kålen holder svampene i live. Se [[Intercropping og levende bunddække]].
